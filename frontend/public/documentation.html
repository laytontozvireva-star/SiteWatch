SiteWatch

Documentation

SiteWatch helps developers monitor website errors and view website health information from one dashboard.

Features

  • Register websites for monitoring.
  • Collect and review supported website error reports.
  • View monitoring activity and alerts.
  • Connect a Vercel account to access supported project and deployment information.

Connecting Vercel

Where the Vercel integration is enabled and configured, users can authorize a connection to their Vercel account. SiteWatch can use the granted permissions to retrieve supported project and deployment information. Configured deployment webhooks can update deployment status in SiteWatch.

Available features depend on the current release, granted permissions, and correct configuration. Do not share access tokens, API keys, or client secrets.
